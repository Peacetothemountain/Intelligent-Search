# No AI Markings Rule

Before running ./gradlew assembleRelease or finalizing a release, you MUST ensure that the codebase has been completely scrubbed of any comments, metadata, or markings indicating that the code was developed, generated, or assisted by AI (e.g., ChatGPT, Gemini, Antigravity, LLM, Agents).

- Remove all // Generated by AI or // Written by ChatGPT comments.
- Do NOT alter actual user-facing AI features (e.g. Ask Gemini buttons). This rule applies strictly to the source code comments and metadata.
