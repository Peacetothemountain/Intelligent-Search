# Intelligent Search

Intelligent Search is a fast, customizable, pixel-inspired search overlay and home screen widget application for Android.

## Features

- **Google Pixel Search Bar & Overlay**: Native Google Pixel Launcher styling with dynamic Material You three-color theme support and System Design colorful modes.
- **RenderThread GPU Motion**: Seamless 120Hz expansion and gesture return animations tuned with critically damped spring physics.
- **Deep System Integration**: Direct search integration for installed apps, system settings, contact shortcuts, web engines, and file search.
- **Customizable Widgets**: Full customization for search bar layout, background transparency, voice actions, and shortcut buttons.
- **Privacy First**: Local search history and clipboard permissions managed with user consent.

## Build Requirements

- Android Studio Jellyfish or newer
- JDK 17
- Android SDK 35 (Android 15+) / Android 17 compatibility target
