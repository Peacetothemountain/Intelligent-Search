# Security Policy

## Supported Versions

The following versions of Intelligent Search currently receive security updates and privacy patches:

| Version | Supported          |
| ------- | ------------------ |
| v8.x    | :white_check_mark: |
| v7.x    | :white_check_mark: |
| < v7.0  | :x:                |

## Reporting a Vulnerability

NB Designs takes application security and user privacy seriously. If you discover a security vulnerability or privacy bug in Intelligent Search, please follow these reporting guidelines:

1. **Do NOT open a public GitHub Issue** for security vulnerabilities.
2. Email your discovery details directly to **NB Designs Security Support**:
   - **Email**: [support.nbdesigns@gmail.com](mailto:support.nbdesigns@gmail.com)
3. Please include:
   - Steps to reproduce the issue or proof of concept.
   - Affected device configuration and Android OS version.
   - Any relevant logs or stack traces.

### Response Commitment
- **Acknowledgement**: We acknowledge receipt of vulnerability reports within 48 hours.
- **Remediation**: Verified security issues will be patched and released via an emergency release update.
